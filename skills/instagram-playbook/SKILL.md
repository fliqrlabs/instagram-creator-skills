# instagram-playbook

The knowledge the other skills in this pack share, kept in one place so it stays consistent and is updated once. Install it with the others: every skill reads from `../instagram-playbook/`.

| File | What's in it |
|---|---|
| [`algorithm.md`](algorithm.md) | what the ranker rewards, keyword CTAs, the first 60 minutes, Reels, carousels, stories, safe zones, captions and hashtags, outlier metrics, timing |
| [`hooks.md`](hooks.md) | 30 hook formulas by goal (SEND / SAVE / COMMENT / FOLLOW / LEAD), and what kills a hook |
| [`safety.md`](safety.md) | the rules every skill follows: approval gate, no fabrication, untrusted content, platform rules, honest promises, tool-neutral output, regulated claims and disclosure |
| [`connectors.md`](connectors.md) | how skills find live data, the Fliqr AI connector's capability map, a complete `create_automation` payload, limits |
| [`creator-profile-template.md`](creator-profile-template.md) | the profile `creator-brain` fills in and every skill reads |
| [`post-log.md`](post-log.md) | the log of approved posts (formula, keyword, funnel) that lets `growth-audit` say which formulas win |

## Answering directly

When the creator asks a general question ("how does the algorithm work now?", "is comment-to-DM allowed?", "what's a good hook?"), answer from these files in plain language, and say which file the answer comes from. If a file and Instagram's current behaviour disagree, Instagram is right. Say so, and suggest updating the file.
